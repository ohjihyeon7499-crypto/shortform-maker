# 🎬 숏폼 메이커

브라우저에서 바로 쓰는 **9:16 세로 숏폼 영상 편집기**입니다. 설치나 서버 없이 사진·영상·텍스트 슬라이드를 이어 붙이고, 자막·제목·배경음악을 넣어 영상 파일(MP4/WebM)로 저장할 수 있습니다.
유튜브 쇼츠, 인스타 릴스, 틱톡용 영상을 만들 수 있습니다.

## 실행 방법

```bash
# 이 폴더에서 아무 정적 서버나 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`index.html`을 더블클릭해서 열어도 동작하지만, 로컬 서버로 여는 쪽이 더 안정적입니다. **Chrome이나 Edge 최신 버전**을 권장합니다.

## 🤖 틱톡 자동 업로드 (토스 링크)

게시물 목록만 적어 두면 영상 제작 → 링크 모음 페이지 → 틱톡 업로드까지 자동으로 합니다. 👉 [automation/README.md](automation/README.md)

## 기능

| 기능 | 설명 |
| --- | --- |
| 클립 추가 | 사진·영상 여러 개를 한 번에 추가(버튼 또는 드래그 앤 드롭), 텍스트 슬라이드 추가 |
| 클립 편집 | 순서 변경, 삭제, 사진 길이 설정, 영상 구간 자르기(시작/끝), 원본 소리 볼륨 |
| 화면 맞춤 | 흐린 배경 / 꽉 채우기 / 원본 비율 — 가로 영상도 세로 화면에 자연스럽게 배치 |
| 자막 | 클립마다 자막 입력, 한글 자동 줄바꿈, 크기·색·위치·스타일(외곽선/박스/기본), 등장 애니메이션 |
| 상단 제목 | 영상 전체에 고정으로 보이는 제목 |
| 효과 | 클립 간 페이드 전환, 사진 줌(Ken Burns) 효과, 하단 진행 바 |
| 배경음악 | 음악 파일 추가, 볼륨 조절, 끝부분 자동 페이드아웃 |
| 내보내기 | 1080×1920 30fps, 브라우저가 지원하면 MP4, 아니면 WebM |

단축키: `Space` 재생/일시정지

## 구조

```
index.html   화면 구성
style.css    스타일
app.js       타임라인, 캔버스 렌더링, 오디오 믹싱, 녹화
```

- 미리보기와 내보내기 모두 같은 `<canvas>` 렌더러를 사용합니다.
- 오디오는 Web Audio API로 영상 원본 소리와 배경음악을 섞어 스피커와 녹화 스트림으로 동시에 보냅니다.
- 내보내기는 `canvas.captureStream()` + `MediaRecorder`로 **실시간 녹화**를 하므로 영상 길이만큼 시간이 걸립니다. 녹화 중에는 탭을 열어 두세요.

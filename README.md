# 🎬 숏폼 메이커

브라우저에서 바로 쓰는 **9:16 세로 숏폼 영상 편집기**입니다. 설치나 서버 없이 사진·영상·텍스트 슬라이드를 이어 붙이고, 자막·제목·배경음악을 넣어 영상 파일(MP4/WebM)로 저장할 수 있습니다.
유튜브 쇼츠, 인스타 릴스, 틱톡용 영상을 만들 수 있습니다.

## 실행 방법

설치 없이 **링크만 열면** 바로 쓸 수 있어요. PC와 폰 모두 가능해요.

- 웹사이트 주소: https://ohjihyeon7499-crypto.github.io/shortform-maker/ (GitHub Pages를 켠 뒤부터 열려요)

### GitHub Pages 켜는 방법 (처음 한 번만)

1. 저장소의 **Settings → Pages**로 들어가요.
2. **Source**를 `Deploy from a branch`로 골라요.
3. **Branch**에서 이 앱이 있는 브랜치와 `/ (root)` 폴더를 고르고 **Save**를 눌러요.
4. 1~2분 뒤에 위 주소가 열려요.

### 내 컴퓨터에서 실행하기 (개발용)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

**Chrome이나 Edge 최신 버전**을 권장해요.

## 기능

| 기능 | 설명 |
| --- | --- |
| 클립 추가 | 사진·영상 여러 개를 한 번에 추가(버튼 또는 드래그 앤 드롭), 텍스트 슬라이드 추가 |
| 클립 편집 | ⠿ 손잡이로 끌어서 순서 변경, 복제, 삭제, 사진 길이 설정, 영상 구간 자르기, 원본 소리 볼륨 |
| 화면 맞춤 | 흐린 배경 / 꽉 채우기 / 원본 비율 — 가로 영상도 세로 화면에 자연스럽게 배치 |
| 자막 | 클립마다 자막 입력, 한글 자동 줄바꿈, `*별표*` 강조색, **한 줄씩 순서대로** 표시, 등장 애니메이션 |
| 글꼴 | 노토 산스, 검은고딕, 도현체, 주아체, 나눔손글씨 펜 |
| 상단 제목 | 영상 전체에 고정으로 보이는 제목 (강조색 지원) |
| 전환 효과 | 페이드 / 밀어내기 / 줌 / 화이트 플래시 / 없음 |
| 효과 | 사진 줌 인·아웃(Ken Burns), 하단 진행 바 |
| 배경음악 | 음악 파일 추가, 볼륨 조절, 끝부분 자동 페이드아웃 |
| 자동 저장 | 작업 내용이 브라우저(IndexedDB)에 자동 저장돼서 새로고침해도 그대로 남음 |
| 내보내기 | 1080×1920 30fps 영상(MP4 또는 WebM), 썸네일 PNG, 자막 SRT 파일 |

단축키: `Space` 재생/일시정지, `←` `→` 1초 이동 (`Shift`와 함께 누르면 5초)

## 구조

```
index.html   화면 구성
style.css    스타일
app.js       타임라인, 캔버스 렌더링, 오디오 믹싱, 녹화
```

- 미리보기와 내보내기 모두 같은 `<canvas>` 렌더러를 사용합니다.
- 오디오는 Web Audio API로 영상 원본 소리와 배경음악을 섞어 스피커와 녹화 스트림으로 동시에 보냅니다.
- 내보내기는 `canvas.captureStream()` + `MediaRecorder`로 **실시간 녹화**를 하므로 영상 길이만큼 시간이 걸립니다. 녹화 중에는 탭을 열어 두세요.
